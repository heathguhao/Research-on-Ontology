# 第八篇《构建本体的三种方法》修改方案

## ISSUE I8-01：明确三条方法是证据路径而非来源穷尽

- **优先级**：P1
- **类型**：逻辑边界
- **评审状态**：评审通过，未执行；实施须另行取得明确授权。
- **问题**：语义、语法和语用提供了三种重要的取证视角，但它们不是一张封闭的流程清单。文章需要避免让读者误以为，只要完成三套固定步骤，就已经穷尽自然语言中所有能够支持本体构建的证据。
- **修改动作**：明确说明三条方法是组织和检验语言证据的基本路径，而不是来源穷尽或流程完备性证明。实际构建中可以组合使用三条路径，也可以根据语言材料和概念问题采用其他取证方式。这里的开放性仍以自然语言为唯一入口，不增加物理模型、测量、数据结构或现场实践等所谓“非语言来源”。
- **建议落点**：摘要、第 1 节、第 2 节方法边界。
- **验收标准**：正文明确写出“三条路径是证据路径，不是来源穷尽”；同时与全书“自然语言是唯一入口”的立场一致，不引出新的平行来源。

## ISSUE I8-02：增加多层本体对齐和反向吸收（不采纳）

- **优先级**：P1
- **类型**：组织治理
- **评审状态**：不采纳，关闭，未执行。
- **原建议**：建立集团核心本体、专业本体、二级单位扩展和现场场景之间的多层对齐、偏离上报与反向吸收机制。
- **不采纳理由**：本体必须集权统一。一个公司只能有一个本体，不存在由不同组织层级分别持有、再相互对齐的多层本体。专业领域、二级单位和现场可以提供语言材料和修订建议，但不能各自建立拥有独立定义权的本体。
- **关闭边界**：不增加多层本体、偏离声明、分层自治或反向吸收机制。本体的所有定义由组织体内的主权者统一确立；来自各处的材料只能作为主权者修订统一本体的参考。

## ISSUE I8-03：把候选流程绑定到量化证据（不采纳）

- **优先级**：P1
- **类型**：证据验证
- **评审状态**：不采纳，关闭，未执行。
- **原建议**：用贯穿案例记录候选、专家修改、冲突、发布周期和业务结果，并比较人工、模型和混合流程的量化表现。
- **不采纳理由**：目前没有可以公开并负责的数据，不能提供这类案例和指标。强行补充只会制造虚假的实证感，也会使文章偏离构建本体的思想方法。
- **关闭边界**：不补案例，不制作量化比较，不暗示存在不可公开的实验。正文中如果存在依赖这些证据的效率、质量或组合优势判断，后续只能弱化为有限判断；无法可靠成立的，直接删除。

## ISSUE I8-04：在公开文章中展开内部技术制品边界（不采纳）

- **优先级**：P2
- **类型**：工程边界
- **评审状态**：不采纳，关闭，未执行。
- **原建议**：在文章中公开区分内部机器可读定义、治理记录、运行实例和执行能力，并说明其结构与引用关系。
- **不采纳理由**：这些内容会触及不对外披露的技术实现和商业机密。第八篇只讨论构建本体的思想与方法，不需要展示内部技术制品如何组织，也不需要通过公开实现细节来证明方法成立。
- **关闭边界**：不增加内部技术制品映射表，不讨论其字段、结构、边界或相互引用关系。公开正文宁可少写，也不得暴露能够还原内部实现的信息。
