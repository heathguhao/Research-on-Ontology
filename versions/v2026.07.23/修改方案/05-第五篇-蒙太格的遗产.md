# 第五篇《蒙太格的遗产》修改方案

## ISSUE I5-01：与第一篇统一理论路线的论述强度

- **优先级**：P0
- **类型**：逻辑边界
- **评审状态**：评审通过，未执行；实施须另行取得明确授权。
- **问题**：第一篇和第五篇讲的是同一条从自然语言形式化走向工程本体的路线，不能让第五篇看起来像是在纠正第一篇。两篇需要用一致的说法解释：为什么要经过一阶逻辑、描述逻辑和三元结构等不同形式，以及每一步保留了什么、舍弃了什么。
- **修改动作**：统一两篇的理论口径。把这条路线写成从哲学理想到工程实现的逐步转化：蒙太格语义提供完整理解语言的方向，后续形式根据具体任务逐渐收束表达范围，以换取清楚、可计算和可实现。不要把这条路线说成逻辑定理自动推出的唯一架构，也不要把工程收束写成对哲学理想的否定。
- **建议落点**：摘要、第 3 节、第 4 节、结论。
- **验收标准**：第一篇和第五篇对一阶逻辑的能力边界、三元结构的地位以及整条转化路线表述一致；两篇形成前后推进，而不是后篇评价或纠正前篇。

## ISSUE I5-02：建立从哲学到工程的四步转化

- **优先级**：P0
- **类型**：逻辑边界
- **评审状态**：按委托人意见改写后通过，未执行；实施须另行取得明确授权。
- **问题**：原建议把哲学命题、形式结论和工程判断分成不同“强度”，容易让人误以为哲学只是较弱的类比，只有工程实现才算可靠。这不符合本系列的路线。哲学不是等待工程纠正的错误起点，而是提出世界观、核心概念和价值方向；真正需要说明的是，这些主张如何一步步获得工程形态。
- **修改动作**：不用四种强度标签，改为四步转化：
  1. **哲学命题**回答我们如何理解世界、语言和意义，确定整条路线为什么成立以及要追求什么；
  2. **形式表达**把哲学命题中的概念、关系和判断条件写清楚，使其能够被讨论和推理；
  3. **工程选择**根据任务和计算条件收束表达范围，说明保留了哪些核心承诺、暂时放下了哪些复杂性；
  4. **系统实现**把选择后的结构落实为类型、规则、接口和行动，并检查系统是否按预期运行。
- **转化原则**：四步不是从“错误”走向“正确”，也不是从“弱论述”走向“强论述”。后一步为前一步提供可操作的形态，前一步为后一步提供方向和意义。工程实现不能反过来取消哲学命题，只能说明某种实现是否充分承接了它。
- **建议落点**：所有命题框、从蒙太格到工程本体的过渡段。
- **验收标准**：读者能够沿着“哲学命题—形式表达—工程选择—系统实现”看见一条连续路线；文章既不把哲学冒充为具体实现已经正确的证明，也不把工程上的限制写成哲学主张失败。

## ISSUE I5-03：加入非语言来源和真实性入口（不采纳）

- **优先级**：P1
- **类型**：工程边界
- **评审状态**：不采纳，关闭，未执行。
- **原建议**：在自然语言之外，增加物理模型、测量系统、数据模式、行业标准和组织实践等独立的本体来源，并另设真实性入口。
- **不采纳理由**：本系列坚持语言是认识世界和形成共同知识的唯一入口。物理模型、测量结果、数据结构、行业标准和组织实践，只有经过命名、解释和陈述，才成为公司能够理解和纳入本体的内容。它们不是不经过语言就能直接形成承诺的平行来源。即便是公式、数据表、模型和程序结构，也必须进入自然语言所提供的意义世界，才能被理解为何物、说明什么以及为何值得相信。
- **立场说明**：“语言的边界就是世界的边界”在本系列中不是装饰性的引语，而是自然语言工程化路线的哲学前提。第五篇继续从自然语言形式语义走向工程本体，不增加所谓“没有自然语言材料时”的另一条起源路线。
- **关闭边界**：不增加多来源输入表，不把测量、模型、标准或实践写成与语言并列的本体来源。正文仍可讨论它们，但必须说明它们如何通过语言获得意义并进入本体。

## ISSUE I5-04：把“工程妥协”改写为可治理的选择政策

- **优先级**：P1
- **类型**：战略引导
- **评审状态**：评审通过，未执行；实施须另行取得明确授权。
- **问题**：“工程妥协”容易被理解为计算机能力不足，所以只能被动放弃哲学理想。实际上，从完整的语言理解走向可运行的本体，是企业根据自身目的主动决定表达什么、做到哪一步。
- **修改动作**：把“工程妥协”改写为可治理的工程选择。说明企业根据任务的重要性、推理要求和实际能力，决定哪些核心认识必须被统一表达，哪些判断必须能够追溯，哪些行动必须受符号约束，哪些复杂内容暂时保留在自然语言中。这里的“治理”是公司对本体范围和表达方式的主动选择，不展开权限角色或繁复审批制度。
- **建议落点**：标题释义、工程降维段、结论。
- **验收标准**：文章不再把工程化写成被动退让，而是写成公司为了形成统一、可运行认识而作出的主动选择；同时保留哲学理想对工程方向的引领作用。
