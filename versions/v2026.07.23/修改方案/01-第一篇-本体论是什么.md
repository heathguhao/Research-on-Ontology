# 第一篇《本体论是什么》修改方案

## ISSUE I1-01：修正“一阶逻辑可判定底线”的矛盾

- **优先级**：P0
- **类型**：逻辑边界
- **评审状态**：评审通过，未执行；实施须另行取得明确授权。
- **问题**：摘要把一阶逻辑称为“可判定底线”，容易让人理解成：只要把问题写成一阶逻辑，计算机就一定能在有限时间内算出结果。事实并非如此。一阶逻辑中的一般问题并不都能保证得到有限时间内的答案，只有经过限制的某些部分和任务才可以。
- **修改动作**：删去“可判定底线”这一说法，改成更直白的“工程形式化的起点”或同等含义的表述。随后说明：一阶逻辑提供了较清楚的表达框架，但工程系统仍要根据具体任务限制可用的表达和推理范围，才能保证程序可运行、结果可检查。正文尽量不用“半可判定性”“描述逻辑片段”等术语堆叠；确有必要时，先用日常语言说明，再补术语。
- **建议落点**：摘要、关于逻辑压缩路线的段落、描述逻辑引入段。
- **验收标准**：全文不再出现“一阶逻辑整体可判定”“一阶逻辑是可判定底线”之类表述；读者不需要逻辑学背景，也能看懂“一阶逻辑提供表达基础，但可运行性仍来自进一步限制”。

## ISSUE I1-02：删除三元结构的最低公共格式强断言

- **优先级**：P0
- **类型**：逻辑边界
- **评审状态**：评审通过，未执行；实施须另行取得明确授权。
- **问题**：三元结构很有用，但不能承载自然语言中的全部意义。事件、时间、责任、状态变化和复杂因果关系，都可能需要比“主体—关系—客体”更多的结构。因此，把三元结构称为自然语言的“最低公共格式”，说得过满。
- **修改动作**：删除“自然语言最低公共格式”的强断言，把三元结构写成一种常用、稳定、便于查询和交换的基础表达方式。同时用简短例子说明：遇到事件、过程、时间和责任等内容时，需要补充其他结构。
- **建议落点**：三元结构定义、垂类符号学模型总结、全文结论。
- **验收标准**：不再把三元结构称为自然语言意义上的最低公共格式；既说明它为什么有用，也说明它不能单独表达什么。

## ISSUE I1-03：区分可判定性、一致性与真实性

- **优先级**：P0
- **类型**：逻辑边界
- **评审状态**：评审通过，未执行；实施须另行取得明确授权。
- **问题**：正文把三个不同问题混在了一起：程序能不能算完，知识库内部有没有互相冲突的说法，以及这些说法是否符合现实。程序能够给出答案，不代表知识库没有矛盾，更不代表答案一定是真的。
- **修改动作**：分别说明三个概念：可判定性回答“程序能不能按规则算完”；一致性回答“已有事实和规则会不会互相冲突”；真实性回答“这些内容是否符合现实”。如果知识库内部发生冲突，系统应当把冲突暴露出来或停止普通推理，不能把一个形式上推得出的结果直接当成现实事实。
- **建议落点**：清晰性、连贯性、可工程化真理和结论段。
- **验收标准**：正文用普通读者能够理解的话说清三个概念，并至少用一个简短例子说明“算得出来”不等于“没有矛盾”，也不等于“符合现实”。这一修正用于厘清技术边界，不降低“可工程化真理”的哲学和战略价值。

## ISSUE I1-04：扩大本体输入来源（不采纳）

- **优先级**：P1
- **类型**：工程边界
- **评审状态**：不采纳，关闭，未执行。
- **原建议**：把语言、数据、标准、模型、测量和实践并列为本体的不同输入来源，弱化自然语言工程化的起点地位。
- **不采纳理由**：这条建议偏离了本系列的基本立场。工程、科学、标准、模型、数据和组织实践要成为人能够共同理解、讨论和建模的知识，都必须通过语言得到表达；数学公式、数据模型、标准条文和程序接口，都是语言的不同形态。它们不是站在语言之外的另一套认识来源。本系列坚持“语言的边界就是世界的边界”这一哲学方向，并以自然语言工程化作为不可动摇的核心起点。
- **关闭边界**：第一篇不增加所谓“非语言来源”来冲淡主线。后续如讨论数据、测量或模型，只说明它们怎样被语言命名、解释并纳入本体，不把它们写成与语言无关的平行起点。

## ISSUE I1-05：把“可工程化真理”改为可治理业务承诺（不采纳）

- **优先级**：P1
- **类型**：战略引导
- **评审状态**：不采纳，关闭，未执行。
- **原建议**：将“可工程化真理”改为“可治理业务承诺”，或者用治理条件收窄“真理”的含义。
- **不采纳理由**：“可工程化真理”是本系列有意提出的哲学命题和价值主张，不只是企业流程中的一项业务承诺。它要表达的是：组织能够把对世界的认识转化为可表达、可推理、可检验、可传承的共同秩序，并由此形成自己的认知能力和认知主权。改成“业务承诺”会把这一命题降成日常治理术语，失去应有的思想高度和战略分量。
- **关闭边界**：保留“可工程化真理”这一术语及其价值高度。`I1-03` 只负责说明“形式上能够推出”不自动等于“现实中为真”，不构成对本术语的降格或替换。正文可以讨论治理如何保障这种能力，但不能用治理流程取代哲学命题本身。
