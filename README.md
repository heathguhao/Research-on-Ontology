# Ontology Papers — 本体论系列论文

> **声明**：目前研究进展未达到可公开标准，但鉴于文章已在一定范围内流传，故发表于仓库中供后续学习研究之用。

---

## 关于本仓库

本仓库收录了一组探讨**工程本体论（Engineering Ontology）**的系列论文，核心目标是将自然语言工程化为可在工业系统中稳定运行的符号秩序。

四篇论文构成一条完整的理论链：从定义问题出发，经过核心机制分析，解决自演进问题，最终回应垂类场景的落地需求。

---

## 文件说明

| 文件 | 说明 |
|------|------|
| `1 本体论是什么（修订版）.md` | **第一篇**：从蒙太格语法到三元组的大降维——自然语言工程化的理论路径。论证高阶逻辑→一阶逻辑→描述逻辑→三元组的压缩链条，每一步都是为可判定性而主动牺牲表达自由。 |
| `2 本体论的核心是什么.md` | **第二篇**：谓词消解在系统之中。提出 Link（链接）、Property（属性）、Action（动作）三种工程形态，论证"对象不是核心，关系才是"。 |
| `3 本体论下的自演进自学习组织体如何成为可能.md` | **第三篇**：引入洛特曼"符号圈"理论，建立神经符号合流架构——LLM 负责边缘语境感知（系统1），本体论负责核心严格推理（系统2），实现自演进。 |
| `4 符号学作为垂类模型唯一解的方式.md` | **第四篇**：论证垂类大语言模型是伪命题，工业场景唯一解为垂类符号学模型——确定性、可解释、可维护、能指锚定所指。 |

---

## 四篇论文的逻辑链

```
第一篇：定义问题      → 本体论 = 自然语言的工程化
第二篇：找到核心      → 谓词消解在 Link / Property / Action 之中
第三篇：解决演进      → 符号圈：核心可判定 + 边缘可感知 + 边界可互译
第四篇：回答落地      → 通用语言界面 + 垂类符号学内核
```
