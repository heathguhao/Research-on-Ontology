# 本体论系列论文

> **声明**：目前研究进展未达到可公开标准，但鉴于文章已在一定范围内流传，故发表于仓库中供后续学习研究之用。

---

## 文件说明

本目录包含一组探讨**工程本体论**的系列论文，核心目标是将自然语言工程化为可在工业系统中稳定运行的符号秩序。

| 文件 | 说明 |
|------|------|
| `1 本体论是什么（修订版）.md` | **第一篇**：从蒙太格语法到三元组的大降维——自然语言工程化的理论路径。论证高阶逻辑→一阶逻辑→描述逻辑→三元组的压缩链条，每一步都是为可判定性而主动牺牲表达自由。 |
| `2 本体论的核心是什么.md` | **第二篇**：谓词消解在系统之中。提出 Link、Property、Action 三种工程形态，论证"对象不是核心，关系才是"。 |
| `3 本体论下的自演进自学习组织体如何成为可能.md` | **第三篇**：引入洛特曼"符号圈"理论，建立神经符号合流架构——LLM 负责边缘语境感知，本体论负责核心严格推理，实现自演进。 |
| `4 符号学作为垂类模型唯一解的方式.md` | **第四篇**：论证垂类大语言模型是伪命题，工业场景唯一解为垂类符号学模型——确定性、可解释、可维护、能指锚定所指。 |
| `5 蒙太格的遗产：自然语言形式化的理想与工程妥协.md` | **第五篇**：追溯降维路线的理论谱系。Montague 的三重承诺（组合性原理、PTQ 英语片段、内涵逻辑）如何暴露了"用纯逻辑手段处理自然语言全部语义"这一任务的结构性代价。 |
| `6 可能世界与反事实推理.md` | **第六篇**：IL→FOL 降维时放弃的可能世界语义如何被两种可判定的工程方案重建——世界分叉（全局仿真）与变换函数（局部增量推演）。 |
| `7 数字孪生作为同构映射.md` | **第七篇**：工程本体论的交付物。数字孪生 = 双射 + 同态 = 抽象本体 + 映射规则（含数据中台） + Action。三件可逐项验收的产物。 |
| `8 构建本体的三种方法：语义、语法与语用.md` | **第八篇**：莫里斯三分法首次从分析工具变为操作方法。语义方法（FDE 标注，精度）、语法方法（范畴论推导，规模）、语用方法（LLM 归纳，覆盖）——三种方法缺一不可。 |
| `参考资料.md` | 系列论文的参考文献合集。 |
| `论文总纲领.md` | 八篇论文的提纲总览，涵盖核心论点与论证脉络。 |

## 八篇论文的逻辑链

```
第一篇：定义问题      → 本体论 = 自然语言的工程化（降维路线）
第二篇：找到核心      → 谓词消解在 Link / Property / Action 之中
第三篇：解决演进      → 符号圈：核心可判定 + 边缘可感知 + 边界可互译
第四篇：回答落地      → 垂类唯一解：通用语言界面 + 垂类符号学内核
第五篇：追溯谱系      → Montague 的遗产：理想与工程妥协
第六篇：填补空洞      → 反事实推理：世界分叉 + 变换函数
第七篇：交付客户      → 数字孪生：抽象本体 + 数据中台与映射规则 + Action
第八篇：构建方法      → 语义（FDE 标注）+ 语法（范畴论推导）+ 语用（LLM 归纳）
```

前四篇构成理论地基（从定义到落地），第五篇补充理论谱系，第六篇填补 IL→FOL 降维的工程功能空洞，第七篇将理论翻译为交付清单，第八篇回答"本体本身的制造工艺"。
